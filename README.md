
# Smol-Bird
It is a mini console that can run a flappy bird game using a coin cell battery and a 8X8 LED grid. i originally saw someone make a small buisness card that can play video games, so I elaborated off of that and made it to only play flappy bird. also created one for pong. It runs on an ATtiny 1616 Microcontroller.
